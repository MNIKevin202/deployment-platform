# Deployment Platform

A self-hosted Docker deployment and server-management platform.

## Planned capabilities

- Create and manage applications
- Deploy Docker containers
- View container status and logs
- Manage environment variables
- Configure domains and HTTPS
- Deploy from Git repositories
- Manage databases and persistent storage
- Export encrypted migration and disaster-recovery bundles (`deployment-platform migrate export`; import is not yet implemented) — see [docs/MIGRATION_DESIGN.md](docs/MIGRATION_DESIGN.md)
